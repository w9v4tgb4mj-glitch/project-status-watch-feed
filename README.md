# Project Status Watch Feed

This independent GitHub Pages repository serves the compact feed used by the
Project Status Apple Watch complication:

`https://w9v4tgb4mj-glitch.github.io/project-status-watch-feed/watch-status.json`

The feed is intentionally public and contains only project names, health labels,
summary counts, and an update timestamp. It contains no credentials, filesystem
paths, logs, evidence, remediation text, or dashboard content.
